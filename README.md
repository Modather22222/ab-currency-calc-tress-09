# Currency Calc

A compact Flutter (Material 3) currency converter. Enter an amount, pick the
source and target currencies, and get an instant conversion using static,
hardcoded sample rates for 12 major currencies. Star currencies to build a
favorites list: favorites appear as quick-pick chips on the converter and are
listed first on the Favorites tab. All state is in-memory; light and dark
themes follow the system automatically.

Run: `flutter pub get && flutter run` — Tests: `flutter test`
